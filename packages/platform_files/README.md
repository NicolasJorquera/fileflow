# platform_files

Plugin propio de FileFlow (arquitectura v1.0, ADR-04): selector de documentos (SAF) y Photo Picker, copias por streaming hacia y desde la app, compartir con un FileProvider limitado a `files/results/`, recepción de «Compartir» y JPEG con el códec de Android. No requiere permisos de almacenamiento. iOS llega en la 2.0.
